JUDGING RUBRIC

How hackathon projects are evaluated and scored (100 Points Total)

Innovation & Novelty 25 PTS

How original is the idea? Does it take an unconventional approach to a tough challenge or offer a fresh twist on existing paradigms?

  • Original problem statement
  • Differentiation from existing SaaS/apps
  • Creative use of technology
  • First-of-its-kind feature set

Technical Execution 25 PTS

Assesses the depth of code, architectural complexity, choice of frameworks, and execution stability.

  • Modern, robust tech stack integration
  • Code quality & GitHub repository link
  • Handling latency, scale & edge cases
  • Clean architecture & data flow

Impact & Feasibility 25 PTS

Does the project solve a real pain point? Could this transition into a viable product used by thousands of people?

  • Quantifiable real-world value
  • Market potential & user demand
  • Scalability & resource efficiency
  • Measurable outcome metrics

Design & Presentation 25 PTS

Clarity of the pitch, user experience, documentation completeness, and working demo accessibility.

  • Intuitive UI & polished UX
  • Clear pitch & problem-solution alignment
  • Comprehensive README & documentation
  • Working demo video or interactive link
